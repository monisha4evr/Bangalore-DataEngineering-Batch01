1. What is a Compiler?
Definition: A compiler is a program that translates source code into machine code or another lower-level form before execution.

Important points:
- Translates the program before execution.
- Usually processes the program as a whole.
- Reports compilation errors.
- Compiled output can be executed later.
- Examples: C, C++ (commonly compiled languages).

2. What is an Interpreter?
Definition: An interpreter executes a program by processing its instructions at runtime.

Important points:
- Executes code during runtime.
- Often processes instructions incrementally.
- Reports errors when the problematic code is reached.
- Does not necessarily create a standalone executable file.
- Python is commonly described as an interpreted language.

3. Compiler vs Interpreter

Important technical point for students:

Python is commonly called an interpreted language. But internally, standard Python implementation (CPython) does more than directly interpret source code.

Execution flow:
1. We write Python source code.
2. Python checks and compiles it into bytecode.
3. Python Virtual Machine (PVM) executes that bytecode.
4. We get the output.

1. What is Cross-Platform Support?
Definition: Cross-platform means a program can run on different operating systems with little or no modification to its source code.
