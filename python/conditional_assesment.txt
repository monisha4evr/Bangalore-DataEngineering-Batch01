1. Electricity Bill Calculator (3 Marks)

Write a Python program to calculate an electricity bill based on the following units:
- First 100 units – ₹2 per unit
- Next 100 units – ₹3 per unit
- Next 100 units – ₹5 per unit
- Above 300 units – ₹7 per unit
Display the total electricity bill.


units = int(input("Enter electricity units: "))

if units < 0:
    print("Invalid Units")

elif units <= 100:
    bill = units * 2
    print("Electricity Bill:", bill)

elif units <= 200:
    bill = (100 * 2) + (units - 100) * 3
    print("Electricity Bill:", bill)

elif units <= 300:
    bill = (100 * 2) + (100 * 3) + (units - 200) * 5
    print("Electricity Bill:", bill)

else:
    bill = (100 * 2) + (100 * 3) + (100 * 5) + (units - 300) * 7
    print("Electricity Bill:", bill)



2. Find the Largest Number (3 Marks)

Write a Python program to find the largest among three numbers without using the max() function.

If all three numbers are equal, display "All numbers are equal".

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

if a == b == c:
    print("All numbers are equal")

elif a >= b and a >= c:
    print("Largest:", a)

elif b >= a and b >= c:
    print("Largest:", b)

else:
    print("Largest:", c)

4. Leap Year Checker (3 Marks)

Write a Python program to check whether a given year is a leap year or not.

Conditions:
- A year divisible by 400 is a leap year.
- A year divisible by 100 but not by 400 is not a leap year.
- A year divisible by 4 but not by 100 is a leap year.

year = int(input("Enter year: "))

if year <= 0:
    print("Invalid Year")

elif year % 400 == 0:
    print("Leap Year")

elif year % 100 == 0:
    print("Not a Leap Year")

elif year % 4 == 0:
    print("Leap Year")

else:
    print("Not a Leap Year")



5. ATM Withdrawal System (3 Marks)

Write a Python program to simulate an ATM withdrawal.

Conditions:
- Initial balance = ₹10,000.
- Withdrawal amount must be greater than zero.
- Withdrawal amount must be a multiple of 100.
- If the amount is greater than the balance, display "Insufficient Balance".
- Otherwise, deduct the amount and display the remaining balance.
balance = 10000

amount = int(input("Enter withdrawal amount: "))

if amount <= 0:
    print("Invalid Amount")

elif amount % 100 != 0:
    print("Amount must be a multiple of 100")

elif amount > balance:
    print("Insufficient Balance")

else:
    balance = balance - amount
    print("Withdrawal Successful")
    print("Remaining Balance:", balance)

- Equilateral
- Isosceles
- Scalene

a = int(input("Enter first side: "))

c = int(input("Enter third side: "))

if a <= 0 or b <= 0 or c <= 0:
    print("Invalid Sides")

elif a + b > c and b + c > a and a + c > b:

    if a == b == c:
        print("Equilateral Triangle")

    elif a == b or b == c or a == c:
        print("Isosceles Triangle")

    else:
        print("Scalene Triangle")

    print("Invalid Triangle")

8. Income Tax Calculator (3 Marks)

Write a Python program to calculate income tax based on annual income.
- Up to ₹3,00,000 – No tax
- ₹3,00,001 to ₹6,00,000 – 5%
- ₹6,00,001 to ₹9,00,000 – 10%
- ₹9,00,001 to ₹12,00,000 – 15%
- Above ₹12,00,000 – 20%
Calculate tax only on the income falling within each slab.

income = float(input("Enter annual income: "))

if income < 0:
    print("Invalid Income")

elif income <= 300000:
    tax = 0

elif income <= 600000:
    tax = (income - 300000) * 0.05

elif income <= 900000:
    tax = (300000 * 0.05) + (income - 600000) * 0.10

elif income <= 1200000:
    tax = (300000 * 0.05) + (300000 * 0.10) + (income - 900000) * 0.15

else:
    tax = (300000 * 0.05) + (300000 * 0.10) + (300000 * 0.15) + (income - 1200000) * 0.20

if income >= 0:
    print("Income Tax:", tax)



9. Online Shopping Discount (3 Marks)

Write a Python program to calculate the final shopping amount.

Discount conditions:
- Purchase below ₹1,000 – No discount
- ₹1,000 to ₹4,999 – 5% discount
- ₹5,000 to ₹9,999 – 10% discount
- ₹10,000 and above – 20% discount
Additional condition:

- If the customer is a premium member, provide an extra 5% discount on the amount after the first discount.

Display the final amount.

amount = float(input("Enter purchase amount: "))
premium = input("Are you a premium member? (yes/no): ")

if amount < 0:
    print("Invalid Amount")

else:
    if amount < 1000:
        discount = 0

    elif amount < 5000:
        discount = amount * 0.05

    elif amount < 10000:
        discount = amount * 0.10

    else:
        discount = amount * 0.20

    final_amount = amount - discount

    if premium.lower() == "yes":
        extra_discount = final_amount * 0.05
        final_amount = final_amount - extra_discount

    print("Final Amount:", final_amount)


10. Number Classification (3 Marks)

Write a Python program to accept an integer and classify it.

Conditions:
- If the number is positive and divisible by both 3 and 5, display "Positive and Divisible by Both".
- If divisible only by 3, display "Divisible by 3".
- If divisible only by 5, display "Divisible by 5".
- If positive but not divisible by either, display "Positive Number".
- If negative, display "Negative Number".
- If zero, display "Zero".

num = int(input("Enter a number: "))

if num == 0:
    print("Zero")

elif num < 0:
    print("Negative Number")

elif num % 3 == 0 and num % 5 == 0:
    print("Positive and Divisible by Both")

elif num % 3 == 0:
    print("Divisible by 3")

elif num % 5 == 0:
    print("Divisible by 5")

else:
    print("Positive Number")
